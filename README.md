# Java Mini Framework

> ⚠️ **Disclaimer:** This project is a mini framework built strictly for **learning purposes** to understand how frameworks work under the hood without using external web libraries. **It is NOT production-ready and contains known limitations and flaws.**

## 🎯 Purpose & Key Concepts Covered

This repository demonstrates building web application features from scratch, focusing on core framework mechanisms:

- **Routing:** Custom HTTP request routing and handler mapping.
- **JSON Serialization:** Custom serialization logic for Java maps and objects to JSON responses.
- **Exception Handling:** Centralized global exception handling returning standardized error responses.
- **Layering Architecture:** Separation of concerns using Controllers, Services, DTOs, and Repositories.
- **Dependency Injection:** Manual dependency wiring in application bootstrap (`Main.java`).
- **Database Interaction & Migrations:** Custom JDBC repository pattern and lightweight SQL migration runner.

---

*Built for educational exploration of Java network programming, data serialization, and software architecture.*
